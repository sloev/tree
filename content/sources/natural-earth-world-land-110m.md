Used as the coastline geometry layer for the overseas migration map. The dataset provides generalized global land outlines at 1:110m scale; it is intended for world-scale orientation, not precise local navigation. It replaces the hand-drawn six-polygon approximation that made the previous map visibly blocky.

The Langeland inset uses a separate island outline so that the island remains legible at local scale.
